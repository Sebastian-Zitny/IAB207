Event Management & Ticket Booking System
Overview

This project is a full-stack web application developed for IAB207. The system allows users to create accounts, browse events, and book tickets through an integrated SQLite database.

The application was designed to simulate a real-world event management platform with user authentication and booking functionality.

Features

User account registration and login authentication

Secure session-based login system

Event browsing and viewing

Ticket booking functionality

SQLite database integration

Persistent user and booking data storage

Admin/event management capabilities
